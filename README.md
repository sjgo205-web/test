# ⏱ 스탑워치 (Stopwatch)

심플한 디자인의 HTML 기반 스탑워치입니다. 별도 설치 없이 브라우저에서 바로 실행할 수 있습니다.

## 실행 방법

`stopwatch.html` 파일을 브라우저(Chrome, Edge, Firefox 등)로 열면 바로 사용 가능합니다.

## 기능

| 버튼 | 설명 |
|------|------|
| **시작** | 타이머를 시작합니다 |
| **정지** | 타이머를 일시 정지합니다 |
| **랩** | 현재 구간 시간을 기록합니다 (실행 중에만 활성화) |
| **초기화** | 타이머와 모든 랩 기록을 초기화합니다 |

## 시간 표시 형식

```
00:00:00.00
시 : 분 : 초 . 센티초
```

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript (`requestAnimationFrame` 기반 고정밀 타이머)
